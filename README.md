# AI投稿監視機能付き掲示板

## 1. 概要

自然言語処理モデルを活用し、ユーザーが投稿した文章を自動分類する掲示板Webアプリケーションです。

投稿内容をAIモデルで判定し、「適切」と分類された投稿のみデータベースに保存します。「適切」以外のカテゴリに分類された投稿については、警告画面を表示して投稿を拒否する仕組みを実装しています。

Webアプリケーションの開発に加え、日本語テキストデータの前処理、データセットの作成、BERTモデルのファインチューニング、評価、Flaskへのモデル組み込みまで一貫して取り組んでいます。

## 2. 開発目的

- Webアプリケーション開発の経験を活かした、AI機能を持つサービスの開発
- 自然言語処理による投稿内容の自動分類
- 機械学習モデルの学習・評価からWebアプリケーションへの統合までの実践
- ユーザーが安心して利用できる掲示板の実現

## 4. 実装機能

### ユーザー管理
- ユーザー登録
- ログイン・ログアウト
- パスワードのハッシュ化による保存
- アカウント設定・削除

### 掲示板機能
- 投稿の作成・一覧表示
- 投稿の編集・削除
- 投稿者本人のみ編集・削除できるアクセス制御
- ページネーション

### AI投稿監視機能
- 投稿本文の日本語テキスト分類
- BERTモデルによる8クラス分類
- 「適切」と分類された投稿のみデータベースに保存
- それ以外のカテゴリに分類された投稿に対する警告表示
- 投稿判定結果と予測確率の取得

## 5. AIモデルの開発

### データセットの作成・前処理

日本語の有害表現を含むテキストデータセットを利用し、学習用データを整備しました。

- テキストデータの確認・分析
- 不要なデータの確認と前処理
- 投稿内容へのカテゴリラベル付け
- 学習・検証・テストデータへの分割
- カテゴリごとのデータ件数の確認

### 分類カテゴリ

以下の8クラスを分類対象としています。

1. 適切
2. 卑語
3. 差別
4. 迷惑行為
5. 猥褻
6. 出会い・プライバシー侵害
7. 違法行為
8. 偏向表現

### モデル学習

- 事前学習済み日本語BERTを利用
- Hugging Face Transformersによるファインチューニング
- 学習率、バッチサイズ、エポック数などの学習パラメーターの設定
- 学習データ・検証データを利用したモデル学習と評価
- 学習済みモデルおよびトークナイザーの保存

### モデル評価

scikit-learnを利用し、テストデータに対して以下の指標で評価します。

- Accuracy（正解率）
- Precision（適合率）
- Recall（再現率）
- F1-score
- 混同行列

## 6. 投稿監視の処理フロー

1. ユーザーが投稿内容を入力する
2. Flaskから学習済みBERTモデルを呼び出す
3. 投稿文章を8クラスに分類する
4. 予測カテゴリを確認する
5. 「適切」の場合はデータベースに保存する
6. 「適切」以外の場合は警告画面を表示し、保存しない

## 9. 注意事項

本アプリケーションの投稿監視機能は機械学習モデルによる予測に基づいています。そのため、不適切な投稿を「適切」と判定したり、適切な投稿を不適切と判定したりする可能性があります。予測結果は完全な判定を保証するものではありません。
