# AI投稿監視機能付き掲示板

## 概要

AIによって投稿内容を自動判定する機能を搭載した掲示板Webアプリケーションです。

ユーザーが投稿した文章を日本語自然言語処理モデルで分析し、不適切な表現が含まれている可能性がある場合は警告画面を表示します。問題がないと判定された投稿はデータベースに保存されます。

FlaskによるWebアプリケーション開発と、BERTを用いた自然言語処理モデルの学習・評価・推論処理の実装を組み合わせた個人開発プロジェクトです。

## 主な機能

### ユーザー管理
- ユーザー登録
- ログイン・ログアウト
- パスワードのハッシュ化
- アカウントごとの投稿管理

### 掲示板機能
- 投稿一覧の表示
- 新規投稿
- 投稿内容の編集
- 投稿の削除
- 投稿者本人による編集・削除の制御
- 1ページ5件のページネーション

### AI投稿監視機能
- 投稿本文を対象としたAI判定
- 不適切な可能性がある投稿の検出
- 検出されたカテゴリと予測確率の表示
- 判定結果に応じた処理の切り替え
  - 適切と判定された場合：投稿をデータベースに保存
  - 不適切と判定された場合：警告画面を表示し、投稿を保存しない
- 投稿編集時にもAI判定を実施

## AIモデルについて

### 使用モデル

- ベースモデル：`cl-tohoku/bert-base-japanese-v3`
- タスク：日本語テキストのマルチラベル分類
- 出力層：7カテゴリそれぞれの予測値
- 推論時の判定：各カテゴリの予測確率に閾値を適用

### 分類カテゴリ

| カテゴリ | 内容 |
|---|---|
| 卑語 | 乱暴な言葉や卑俗な表現 |
| 差別 | 差別的な表現 |
| 迷惑行為 | 迷惑行為に関連する表現 |
| 猥褻 | 猥褻な表現 |
| 出会い・プライバシー侵害 | 出会い目的やプライバシー侵害に関連する表現 |
| 違法行為 | 違法行為に関連する表現 |
| 偏向表現 | 偏向的な表現 |

複数のカテゴリに該当する可能性を考慮し、各カテゴリを独立して判定するマルチラベル分類を採用しています。

どのカテゴリも閾値を超えなかった場合は、検出カテゴリなしとして扱います。ただし、これは必ずしも文章が安全であることを保証するものではありません。

## データセットと前処理

日本語有害テキスト分類用のデータセットとして、[inspection-ai/japanese-toxic-dataset](https://huggingface.co/datasets/inspection-ai/japanese-toxic-dataset) を使用しています。

データセットの確認・加工を行い、投稿テキストと7カテゴリのラベルをモデルの学習に利用できる形式に変換しました。

主な前処理・学習準備は以下のとおりです。

- テキストデータとカテゴリ情報の確認
- 分類対象となる7カテゴリの整理
- マルチラベル形式への変換
- 学習用・検証用・テスト用データへの分割
- 日本語BERTのトークナイザーによるテキストの数値化

データ数が少ないカテゴリも存在するため、カテゴリごとのデータ件数がモデルの学習や評価に与える影響を確認しています。

## 学習と評価

モデルの学習では、各カテゴリの出現頻度に偏りがあることを踏まえ、クラスの不均衡に対応する重み付け学習も試しました。

### 評価指標

- **Precision（適合率）**：不適切と予測したもののうち、実際に該当する割合
- **Recall（再現率）**：実際に該当するもののうち、検出できた割合
- **F1-score**：適合率と再現率の調和平均
- **Validation Loss**：検証データに対する損失

### 重み付け学習モデルの評価結果

検証データに対して、各カテゴリの予測確率を0.5の閾値で判定した際の結果です。

| カテゴリ | 正解陽性数 | 予測陽性数 | Precision | Recall | F1-score |
|---|---:|---:|---:|---:|---:|
| 卑語 | 2 | 0 | 0.000 | 0.000 | 0.000 |
| 差別 | 6 | 3 | 0.667 | 0.333 | 0.444 |
| 迷惑行為 | 8 | 13 | 0.385 | 0.625 | 0.476 |
| 猥褻 | 2 | 0 | 0.000 | 0.000 | 0.000 |
| 出会い・プライバシー侵害 | 0 | 0 | — | — | — |
| 違法行為 | 0 | 0 | — | — | — |
| 偏向表現 | 2 | 1 | 0.000 | 0.000 | 0.000 |

※評価対象の正解陽性数が0のカテゴリは、Recallを評価できません。予測陽性数も0のため、PrecisionとF1-scoreもここでは算出対象外としています。

この結果から、カテゴリによって検出性能に差があることが分かりました。特に「迷惑行為」「差別」では一定の検出ができた一方、ほかのカテゴリでは検出できないケースがありました。

データ数が少ないカテゴリや、検証データに正例が含まれないカテゴリについては、現時点で十分な性能評価ができていません。今後はデータの拡充やラベルの見直し、閾値の調整などを通じて改善する予定です。

## Webアプリケーションへの組み込み

学習済みモデルをFlaskアプリケーションから読み込み、投稿処理の中で推論を実行する構成にしています。

1. ユーザーが投稿内容を入力する
2. Flaskが投稿内容を受け取る
3. 学習済みBERTモデルで各カテゴリの予測確率を計算する
4. 閾値を超えたカテゴリを抽出する
5. 検出結果に応じて投稿保存または警告画面表示を行う

この構成により、モデルの学習だけでなく、実際のWebアプリケーション上で推論結果を利用するところまで実装しています。

## 工夫した点・学んだこと

- FlaskとSQLiteを組み合わせ、ユーザー認証から投稿管理までの一連のWebアプリケーションを実装した
- 日本語BERTを利用し、文章の文脈を考慮する自然言語処理モデルを組み込んだ
- 単一の「適切／不適切」判定だけでなく、複数カテゴリを検出できるマルチラベル分類を採用した
- カテゴリごとのデータ数の偏りを確認し、重み付け学習を試した
- Accuracyだけでなく、Precision・Recall・F1-scoreを使ってカテゴリ別の性能を分析した
- AIの予測結果をWebアプリケーションの投稿フローに組み込み、判定結果に応じた処理を実装した

## 今後の改善予定

- データ数が少ないカテゴリの学習データを拡充する
- カテゴリごとの評価結果を踏まえ、モデルの性能を改善する
- カテゴリ別の閾値を検討する
- 誤検出・見逃しの具体例を分析し、データやモデルを改善する
- 自動テストを追加し、投稿処理やAI判定の動作を検証する
- セキュリティ対策やエラーハンドリングを強化する

## 注意事項

本アプリケーションは学習・開発を目的としたプロトタイプです。AIによる分類には誤検出や見逃しがあり、検出結果だけで投稿内容の安全性を保証することはできません。
